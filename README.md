# E-commerce Business Analysis

## Project Overview

An end-to-end E-commerce Business Analysis project using Python and SQL to analyze sales performance, customer purchasing behavior, product categories, and revenue trends.

The project uses the Brazilian E-Commerce Public Dataset by Olist.

## Tools & Technologies

- Python
- Pandas, NumPy, Matplotlib, Seaborn
- SQL
- SQLite
- Google Colab

## Project Workflow

### 1. Data Analysis using Python

- Data loading and exploration
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Revenue and sales trend analysis
- Customer purchasing behavior analysis

### 2. SQL Business Analysis

- Revenue analysis
- Order and customer analysis
- Product category performance
- Customer segmentation
- Top customers by spending
- Revenue contribution by customer segment

## Key Business Insights

- Analyzed customer purchasing patterns and revenue distribution.
- Identified high-value, medium-value, and low-value customer segments.
- Evaluated product category performance.
- Examined sales and order trends to understand business performance.
